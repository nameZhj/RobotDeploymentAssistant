## 2. 核心借鉴规范 (Design Tokens)

1. **色彩系统**：
   - 背景主色：`#0B0F19` (底色) / `#0F172A` (面板容器)
   - 边框分割：`#1E293B`
   - 主强调色：`#0EA5E9` / `#1E6FFF`
   - 成功状态：`#10B981`
   - 警告/错误状态：`#F59E0B` / `#EF4444`
2. **四区工作台信息架构**：
   - 顶部：全局状态与主导航（高 50px）
   - 左侧：资源库/阵型/地图管理 Dock（宽 280-320px）
   - 中央：2D 舞台平面 / 3D 视口（支持向心样条与点云加载）
   - 底部：双层时间轴（高 ≥220px，上层动作/下层轨迹，支持多轨对齐与拖拽编辑）
   - 右侧：属性监视与参数配置面板（宽 260-320px）
