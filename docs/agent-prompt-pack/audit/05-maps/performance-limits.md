# 地图管理与渲染性能预算与限制说明 (Performance & Limits)

> 审计依据: Prompt 05 | 范围: 2D 占据栅格与 3D 点云渲染预算

## 1. 内存与显示点数预算

- **原始点云完整性**: 导入的原始 `.pcd` 文件保存在 `data/maps/` 托管目录中，保持原始字节完整无损。
- **2D 栅格投射限制**:
  - 分辨率 (`resolution`): 默认 0.05m (5cm/像素)。
  - 动态包围盒限制: 最大跨度不超过 200m × 200m（栅格图最大 4000 × 4000 像素）。
- **3D 视口渲染降采样预算**:
  - 最大显示点数上限: 30,000 点。
  - 降采样策略: `PcdLoader.downsample` 等间距均匀抽稀，保护渲染帧率不低于 45 FPS。

---

## 2. 存储与安全边界

- **路径遍历防护**: `MapStorageService.resolve_safe_path` 严格执行 `commonpath` 校验，拦截所有 `../` 越界尝试。
- **原子事务写入**: 文件上传先写入 `.staging` 临时目录，完成哈希校验和刷盘 (`os.fsync`) 后再原子替换到正式路径。
- **引用保护**: 处于活跃加载状态或被 `scenes` / `show_projects` / `trajectories` 引用的地图禁止物理删除。
