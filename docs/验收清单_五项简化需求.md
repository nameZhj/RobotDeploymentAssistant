# 舞台编导简化需求验收表

## 1. 地图管理
- [ ] 可从电脑导入合法 PCD 到应用本地地图目录。
- [ ] 非法/损坏 PCD 有错误提示，不留下半文件。
- [ ] 地图列表数据来自真实文件/存储，重启后仍存在。
- [ ] 可安全删除未被项目引用的地图。
- [ ] 被项目引用的地图有保护。
- [ ] 可加载地图到 2D 舞台，地图比例/方向/原点正确。
- [ ] 大文件解析不阻塞 Qt 主线程。
- [ ] 远程建图未实现时不显示假按钮/假进度。

## 2. 2D 单机/群体轨迹
- [ ] 选中指定机器人后可绘制轨迹。
- [ ] 控制点可选择、移动、插入、删除。
- [ ] 使用真实样条/轨迹算法显示平滑轨迹。
- [ ] 轨迹保存、关闭、重开后一致。
- [ ] 可选择多个机器人创建群体轨迹。
- [ ] 群体路径和每台机器人轨迹/目标关系正确。
- [ ] 坐标变换、地图边界和机器人间距检查有效。

## 3. 阵型
- [ ] 基础阵型由真实相对坐标生成，不是静态图片。
- [ ] 可修改间距、旋转和单个槽位。
- [ ] 可将阵型应用到已选择机器人组。
- [ ] 机器人数量不匹配时有明确处理。
- [ ] 阵型沿曲线路径转向时保持相对关系。
- [ ] 保存重开后机器人站位一致。

## 4. 舞蹈/动作/轨迹拖拽编排
- [ ] 动作素材来自真实 YAML/文件/Repository，无假列表。
- [ ] 素材库明确区分远端别名和本地姿态数据。
- [ ] 动作可拖到指定机器人时间轴。
- [ ] 轨迹可拖到单机或群组时间轴。
- [ ] 每个 clip 有稳定资产引用、目标机器人和时间数据。
- [ ] 拖放失败会回滚，不产生幽灵片段。
- [ ] 片段可移动、改时长、删除。
- [ ] 保存项目后重开，时间轴恢复。

## 5. 3D 整体预演
- [ ] 多台机器人模型同时显示。
- [ ] 3D 位置/朝向与 2D 舞台和轨迹一致。
- [ ] 所有机器人共用一个播放时钟。
- [ ] 播放、暂停、继续、跳转、停止真实有效。
- [ ] 可用的本地姿态数据驱动实际关节运动。
- [ ] 只有动作别名时不编造 3D 舞蹈动作，并明确标记不可预览。
- [ ] 显示 SIMULATED/虚拟预演状态，不冒充真机执行。
- [ ] 页面关闭/切换后无残留 QTimer/QThread。

## 6. UI 和回归
- [ ] 同一操作只有一个主要按钮入口。
- [ ] 复用现有 QSS、字体、图标、按钮高度和间距。
- [ ] 无重复顶栏/工具栏、按钮错位、遮挡和文本裁切。
- [ ] 最小窗口和常用窗口尺寸下布局正常。
- [ ] 空状态、加载中、失败、禁用状态清晰。
- [ ] 旧部署助手主页、后端和入口未修改。
- [ ] 相关单测、UI 测试、语法检查通过。
- [ ] stage_director_guard verify 通过。
