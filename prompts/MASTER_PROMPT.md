
```powershell

git diff --stat HISTORICAL_BASELINE..HEAD
git diff --name-status HISTORICAL_BASELINE..HEAD
```

## 3. P0：修复窗口只能打开一次的问题

根据当前架构实施可靠策略：由稳定 GUI 线程拥有 QApplication 和 QWidget；明确窗口关闭后销毁重建还是隐藏复用；销毁时正确清空 manager 引用并允许下一次重建，复用时确认线程和对象有效；Web/Flask 与 Qt 通过线程安全 queued signal/队列通信。不得跨线程直接操作 QWidget。

### P2 — 地图管理和 2D 轨迹

地图管理支持真实本地 PCD 导入、列表、加载、删除、元数据查看；在 2D 画布显示真实点云和正确坐标范围。保存格式、坐标系、单位、边界等必要信息。删除地图前处理轨迹/阵型/项目引用，禁止静默级联丢失。

### P3 — 阵型和动作时间轴

阵型功能支持真实计算、参数编辑、画布预览、保存和加载；群体成员 ID 必须真实存在。常用阵型（横排、纵列、圆形、网格等）可按项目情况实现，但不能只画装饰图形。

禁止 `sin()`、随机数或硬编码波形伪造舞蹈动作；没有真实动作数据时显示明确的“未配置动作”或有定义的静态姿态。禁止启动时自动塞入假 Clip、假群组 ID。时间轴保存必须真实落盘，不能用写死项目编号或假成功提示。
